# Beginner tutorial series

Start with the complete encounter workflow, then teach each major feature with
separate web and iOS episodes where supported. Use the reference film's pale sage
background, dark teal typography, roomy layouts, and authentic app captures.

1. **Your first encounter**: record/upload → processing → review → edit/save →
   complete → discharge → follow-up. Produce a web tutorial, an iOS tutorial, and
   a hybrid version once matching capture fixtures establish continuity.
2. **Record and recover**: recording, audio uploads, interruption recovery, and
   retrying an unfinished upload. Show platform-specific behavior explicitly.
3. **Review with confidence**: transcript/audio comparison, editing, full screen,
   formatting, saving, and completion.
4. **Make templates your own**: clinical note templates, discharge templates,
   importing existing material, and keeping reusable client education separate.
5. **Discharge and follow-up**: review before sending, recipient selection, email
   templates, reply routing, and the inbox.
6. **Keep the practice organized**: patients, encounter history, Today/dashboard,
   search, and team workflows.
7. **Sentinel**: explain flagged encounters and review, using the documented scope
   and without implying automatic outside contact.

Source topics: `content/setup-guide.mdx`, `content/encounters/`,
`content/templates.mdx`, `content/email-templates.mdx`, `content/messages.mdx`,
`content/patients.mdx`, `content/practice.mdx`, and `content/reference/sentinel.mdx`.
