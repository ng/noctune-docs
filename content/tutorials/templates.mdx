# Build templates that write the way you do

Browse included and community templates, duplicate one to adapt, start your own, or import a template you already use and let noctune organize it.

The current library also groups practice templates, supports personal and practice defaults, and keeps saved template instructions separate from locked sections in an existing note. See [Templates](/templates) and [Collaborative Notes](/encounters/collaborative-notes) for the current workflow. The video shows the earlier template layout.
